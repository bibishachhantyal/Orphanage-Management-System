# Database Setup Guide for Orphanage Management System

## Overview
This guide will help each team member set up the MySQL database required for the Orphanage Management System. The database contains 14 tables, indexes, foreign keys, and sample data.

---

## Prerequisites
- XAMPP (or any MySQL server) installed and running
- Git (to pull the latest code)
- IntelliJ IDEA (for testing the connection)

---

## Step 1: Pull the Latest Code
Open a terminal in your project folder and run:
```bash
git checkout main
git pull origin main
